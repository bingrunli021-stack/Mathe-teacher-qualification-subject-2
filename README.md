## 数据边界

唯一教材来源为用户上传的《（科目二瘦版）中公教资高中数学.pdf》。原PDF、扫描页、完整OCR和精校正文均不提交GitHub，也不放在`web`目录。

前端只有Supabase公开key，没有service_role。匿名用户没有教材表读取权限；未在`tq_members`中的登录账号也不能读取。个人事件按`auth.uid()`隔离，只能追加，不能更新或删除历史。每日计划和时间由服务器生成；连续三天未达标后自动减量，不累积旧任务。

## 开发与部署

运行`npm run check`与`npm test`检查前端语法和同步模型。Pages发布目录为`web`，`.github/workflows/pages.yml`负责检查与发布。

数据库迁移依次为`db/schema.sql`、`db/002_event_safety.sql`和`db/003_chapter1_quiz_countdown.sql`。`scripts/build_chapter1_proof.py`与`scripts/build_remaining_proof.py`只读取仓库外的PDF、OCR和人工校订记录，并把私有导入数据输出到仓库外目录。
